## Shared by the family

Every conversation is kept on your server and belongs to the whole family. Anyone can open it from any client, the web chat, the terminal or a satellite, and carry on. Ambrogio has no user accounts, so everyone sees every conversation.

Ambrogio remembers what was said earlier in the same conversation, so you can ask *"Can you make it shorter?"* after a question. A new conversation starts from scratch.

## One answer at a time

Ambrogio answers one message at a time in each conversation, because every answer depends on the ones before. If you write while it is still answering, your message is refused: wait for the answer. Different conversations do not wait for each other.

## When the answer does not arrive

- **"In progress"**: Ambrogio is still writing the answer, even if you closed the page in the meantime. Refresh later and it appears.
- **"I can't complete the response."**: something went wrong, for example the LLM did not answer within 30 seconds. Ask again; [Troubleshooting](../../how-to/troubleshoot/#every-answer-is-i-cant-complete-the-response) helps if it keeps happening.
- **Interrupted**: the backend was restarted while it was answering. Ask again.

Ambrogio never repeats a question by itself.
