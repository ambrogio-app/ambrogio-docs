## What you install

Ambrogio is split into four programs, each in its own Git repository.

<CardGrid>
	<Card title="Backend" icon="laptop">
		The server. It stores conversations, sends each request to an AI agent, and turns speech into text and back. You run one per home. Repository: `ambrogio-backend`.
	</Card>
	<Card title="Terminal client" icon="seti:shell">
		A chat window in your terminal. Use it from any computer that can reach the backend. Repository: `ambrogio-cli`.
	</Card>
	<Card title="Web chat" icon="seti:html">
		The same chat in a browser, served by an optional container next to the backend. Repository: `ambrogio-web`.
	</Card>
	<Card title="Voice satellite" icon="comment-alt">
		A small program for a device with a microphone and a speaker, such as a Raspberry Pi. It waits for "Hey Jarvis" and lets you speak to Ambrogio. Repository: `ambrogio-satellite`.
	</Card>
</CardGrid>

You always need the backend. The terminal client, the web chat and the satellites are optional, and you can run as many of them as you like.
